# UI Reference Images

This folder is for **UI-specific visual references** (HUD, windows, iconography, pixel motifs, and UI mood boards).

> Source: images shared in chat by the project owner.

## File Naming Convention
Use: `uiref_<theme-or-system>_<subject>_<v#>.png`

Examples:
- `uiref_pastel_pixel_widget_layout_v1.png`
- `uiref_pink_heart_healthbar_states_v1.png`

## References To Place Here

1. `uiref_pastel_pixel_widget_layout_v1.png`
   - Pink/pastel phone-home screen style with retro windows, hearts, and icon tiles.

2. `uiref_pastel_pixel_ui_elements_collage_v1.png`
   - Pixel UI collage including fake OS windows, search bar, error stack, and icon motifs.

3. `uiref_purple_pink_pixel_icon_pack_v1.png`
   - Sticker/icon set with hearts, keys, wings, cakes, and bandaid motifs.

4. `uiref_pink_heart_healthbar_states_v1.png`
   - 4-state heart-based health bar reference on dark background.
