# Character Art References

This folder is for **character-specific art references**.

> Source: images shared in chat by the project owner.

## File Naming Convention
Use: `charref_<group-or-name>_<pose-or-context>_<v#>.png`

Examples:
- `charref_group_supernova_cover_v1.png`
- `charref_orange_twintails_reach_pose_v1.png`
